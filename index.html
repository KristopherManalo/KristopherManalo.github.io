SystemVerilog · C · Intel Quartus Prime · ModelSim

Designed and implemented a custom RISC processor architecture using SystemVerilog, alongside a C-based assembler for generating machine code. The project involved defining a custom instruction set, implementing its hardware logic, and developing the software toolchain required to target the architecture. The assembler incorporates preprocessing and code generation to handle control flow, including instruction insertion and reordering where necessary to accommodate architectural limitations. The processor was simulated and evaluated using ModelSim and Intel Quartus Prime, providing an opportunity to explore the relationship between instruction set design, hardware implementation, and compiler-level abstractions.

Go · gRPC · Protocol Buffers · SQLite · FFmpeg · HTTP

Developed a distributed video storage system in Go, using a network of storage nodes to manage and retrieve video files. The system uses gRPC and Protocol Buffers for communication between nodes, with consistent hashing to distribute files across the network. It supports node addition and removal, including file migration to maintain data availability as the cluster changes. A Go-based command-line interface provides node management, while an HTTP backend handles video uploads and retrieval. The project also integrates FFmpeg for video processing and SQLite for metadata storage.
